# 雅思词汇真经 · 分章默写手册

把《雅思词汇真经》（刘洪波 编著）整理成可直接在浏览器里用的静态网页：**22 章、3631 个词、878 个逻辑词群**，每个词都配中英对照例句，中文可一键隐藏，用来自测默写。

在线预览：**https://prstcoder.github.io/ielts-vocab-zhenjing/**

---

## 特点

- **按书里的逻辑词群分组**：不是按字母、也不是乱序。同一词群的词排在一起，组与组之间有明确分隔，跟书上的排版逻辑一致。例如第 1 章开头：
  - 词群 01：`atmosphere · hydrosphere · lithosphere`
  - 词群 02：`oxygen · oxide · carbon dioxide · hydrogen`
  - 词群 03：`core · crust · mantle`
- **每个词都带音标**：采用国际音标（IPA），英式发音，列表版排在单词下方、卡片版排在单词右侧。
- **两种版式**：纯列表版（快速过词）+ 例句卡片版（带中英例句）。
- **默写模式**：一键隐藏所有中文（词义 + 例句译文），只留英文；也可单独隐藏词义、隐藏音标或隐藏译文，开关状态记在浏览器里。
- **搜索过滤**：输入中文或英文即时过滤，`/` 键聚焦搜索框，`Esc` 清空。
- **生词本**：每个单词右侧有 ☆，点一下收进生词本（`shengci.html`），可跨章节汇总、搜索、导出 TXT / 备份 JSON；「只看生词」开关可把一章里标记过的词单独拎出来。
- **背诵（逐词自测）**：独立的背诵功能，跟生词本分开算。点右下角「背诵本单元」，词卡一个一个跳出来——先自己回想，点卡片看释义；「不认识」就自动收进生词本并排在 10 分钟后重来，「认识」就按 1→2→4→8→15→30→90 天的间隔往后推。右上「只背到期」可以只过今天该复习的词。桌面端 `空格` 看释义、`1` 不认识、`2` 认识、`Esc` 退出。
- **衍生词**：1454 个词附有派生词（如 `atmosphere → atmospheric adj.`、`educate → education · educator`），默写模式下与释义一起隐藏；点 ☆ 或背诵时标「不认识」，会按「☆带衍生」开关把这个词的派生词一起收进生词本。
- **闪卡复习**：生词本页「开始复习」随机抽词，按遗忘曲线安排到期，点开对答案，`1` 没记住 / `2` 记住了；另有「拼写听写」模式，看中文写英文、逐字判对错。
- **朗读**：单词和例句都能点小喇叭朗读（浏览器自带语音，优先英式发音）。
- **学习统计**：生词本页顶部有连续打卡天数、今日复习、今日新增、掌握率，以及近 14 天复习量柱状图。
- **纯静态**：单个 HTML 文件自带全部样式与脚本，不联网、不依赖任何外部资源，手机上打开也是卡片式排版。

## 数据来源与说明

- 词表与释义以官方配套的《雅思词汇真经》默写词汇表（52 个 List，英译中 / 中译英两册）为准，逐词核对。
- 词群划分依据原书正文中词群之间的分隔线（同栏内行距由 ~14pt 突增到 ~26pt 的位置）。
- 例句取自原书 `[例]` 标注的中英对照句子；原书未提供或扫描不清的 80 条由本项目补写。
- 衍生词按构词规则生成，并逐条用 5 万词频表与词典双重校验（只保留真实常用词），共覆盖 1454 个词；无常用派生词的词条不强行凑数。
- 个别单词在不同章节重复出现时，本仓库按章节各保留一次。

## 本地使用

下载后直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

生词本数据存在浏览器 localStorage 里（键名 `vj-book`），背诵进度单独存在 `vj-rec`，设置项在 `vj-set` / `vj-tts`，学习统计在 `vj-stat`，全部只在本机，不上传任何服务器；换设备或清缓存前请用「备份 JSON」导出，换设备后「导入备份」即可恢复。

> 注意：Chrome 对 `file://` 打开页面的本地存储有限制，若要稳定保存生词本，建议用本地服务器（`python3 -m http.server`）或直接访问上面那个 GitHub Pages 地址。
