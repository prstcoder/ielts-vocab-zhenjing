# 雅思词汇真经 · 分章默写手册

把《雅思词汇真经》（刘洪波 编著）整理成可直接在浏览器里用的静态网页：**22 章、3631 个词、878 个逻辑词群**，每个词都配中英对照例句，中文可一键隐藏，用来自测默写。

在线预览：**https://prstcoder.github.io/ielts-vocab-zhenjing/**

---

## 特点

- **按书里的逻辑词群分组**：不是按字母、也不是乱序。同一词群的词排在一起，组与组之间有明确分隔，跟书上的排版逻辑一致。例如第 1 章开头：
  - 词群 01：`atmosphere · hydrosphere · lithosphere`
  - 词群 02：`oxygen · oxide · carbon dioxide · hydrogen`
  - 词群 03：`core · crust · mantle`
- **每个词都带音标**：采用国际音标（IPA），英式发音，列表版排在单词下方、卡片版排在单词右侧。
- **两种版式**：纯列表版（快速过词）+ 例句卡片版（带中英例句）。
- **默写模式**：一键隐藏所有中文（词义 + 例句译文），只留英文；也可单独隐藏词义、隐藏音标或隐藏译文，开关状态记在浏览器里。
- **搜索过滤**：输入中文或英文即时过滤，`/` 键聚焦搜索框，`Esc` 清空。
- **生词本**：每个单词右侧有 ☆，点一下收进生词本（`shengci.html`），可跨章节汇总、搜索、导出 TXT / 备份 JSON；「只看生词」开关可把一章里标记过的词单独拎出来。
- **背诵（逐词自测）**：独立的背诵功能，跟生词本分开算。点右下角「背诵本单元」，词卡一个一个跳出来——单词下面常显**纯英文例句**，先靠例句猜意思；点卡片（或空格）对答案，**释义 + 例句译文 + 衍生词**一起出现。「不认识」就自动收进生词本并排在 10 分钟后重来，「认识」就按 1→2→4→8→15→30→90 天的间隔往后推。右上「只背到期」可以只过今天该复习的词。桌面端 `空格` 看释义、`1` 不认识、`2` 认识、`Esc` 退出。弹层不受「默写模式」影响，开不开隐藏中文都能正常看答案。
- **衍生词**：1454 个词附有派生词（如 `atmosphere → atmospheric adj.`、`educate → education · educator`），默写模式下与释义一起隐藏；点 ☆ 或背诵时标「不认识」，会按「☆带衍生」开关把这个词的派生词一起收进生词本。
- **闪卡复习**：生词本页「开始复习」随机抽词，按遗忘曲线安排到期，点开对答案，`1` 没记住 / `2` 记住了；另有「拼写听写」模式，看中文写英文、逐字判对错。
- **朗读**：单词和例句都能点小喇叭朗读（浏览器自带语音，优先英式发音）。
- **学习统计**：生词本页顶部有连续打卡天数、今日复习、今日新增、掌握率，以及近 14 天复习量柱状图。
- **纯静态**：单个 HTML 文件自带全部样式与脚本，不联网、不依赖任何外部资源，手机上打开也是卡片式排版。

## 数据来源与说明

- 词表与释义以官方配套的《雅思词汇真经》默写词汇表（52 个 List，英译中 / 中译英两册）为准，逐词核对。
- 词群划分依据原书正文中词群之间的分隔线（同栏内行距由 ~14pt 突增到 ~26pt 的位置）。
- 例句取自原书 `[例]` 标注的中英对照句子；原书未提供或扫描不清的 80 条由本项目补写。
- 衍生词按构词规则生成，并逐条用 5 万词频表与词典双重校验（只保留真实常用词），共覆盖 1454 个词；无常用派生词的词条不强行凑数。
- 个别单词在不同章节重复出现时，本仓库按章节各保留一次。

## 多设备同步（可选，默认关闭）

默认所有数据只在本机浏览器。想让手机和电脑共用同一本生词本与背诵进度，用「同步码」——不用注册账号，一串码就是钥匙。

**一次性准备（约 10 分钟）**

1. 打开 [supabase.com](https://supabase.com) 注册（免费）→ New project，等它建好
2. 左侧 **SQL Editor** → 把仓库里的 `supabase-setup.sql` 全文粘进去 → Run
**在网页里开启（已内置配置，不用填地址和 key）**

3. 打开 `shengci.html` → 找到「多设备同步」。面板默认是锁着的，先输入**访问密码**解锁（密码由维护者保管，不写在页面里）
4. 点「生成新的同步码」，得到形如 `K7F3-9QW2-M4` 的一串码
5. 另一台设备打开同一页，输密码解锁后把码粘进输入框 → 点「用这个码」→ 两边自动合并

本仓库页面已内置一个免费的 Supabase 项目（项目地址与 publishable key 直接写在 HTML 里）。这个 key 属于「可公开」的类型，只被授权调用两个 `security definer` 函数，数据表本身对匿名用户完全不可读，放进页面没有安全风险；同步码是从 32 个字符里随机取 10 位（约 10^15 种组合），猜不到别人的码。

想换成**自己的** Supabase 项目：跑完上面第 2 步的 SQL 后，在已启用的面板里点「换配置」，填入你的 `Project URL` 和 `anon` / `publishable` key，再重新生成同步码即可（只影响本机，不改内置默认值）。

**行为说明**

- 数据改动后 2 秒左右自动上传；打开页面、切到后台、手动点「立即同步」都会同步一次
- 合并规则：同一个词取「最后复习时间」较新的那条；每日统计按天取较大值（避免两端各算一遍把数字刷爆）
- 写入带版本校验，两台设备同时改也不会互相覆盖：冲突时先拉最新副本合并再重试
- 关掉同步：点「停用」，本机数据保留；想换码就重新生成
- 密码：输一次就记在本机（`sync-unlock`），不用反复输；点「锁定」可随时锁回去，锁定期间打开页面和自动上传都会暂停
- **码就是钥匙**：谁拿到码谁就能读写你的数据，别公开晒；数据只存在你自己的 Supabase 项目里
- 免费额度（数据库 500MB）够存几十万条学习记录

> **连不上怎么办**：如果面板提示「连不上 xxx.supabase.co」，而浏览器里直接打开那个网址显示 `ERR_CONNECTION_CLOSED` / 一直转圈，那是当前网络到 `supabase.co` 的连接被拦（国内很常见），不是密码或代码的问题。点面板上的「停用」即可回到纯本机使用，生词本和复习进度一条都不会少；跨设备搬数据改用生词本里的「备份 JSON / 导入备份」。

> 同步走的是 `https://` 接口，`file://` 双击打开时可能被浏览器的跨域策略挡住；建议用 GitHub Pages 地址或本地 `python3 -m http.server`。

## 本地使用

下载后直接用浏览器打开 `index.html` 即可，无需服务器、无需联网。

生词本数据存在浏览器 localStorage 里（键名 `vj-book`），背诵进度单独存在 `vj-rec`，设置项在 `vj-set` / `vj-tts`，学习统计在 `vj-stat`，全部只在本机，不上传任何服务器；换设备或清缓存前请用「备份 JSON」导出，换设备后「导入备份」即可恢复。

> 注意：Chrome 对 `file://` 打开页面的本地存储有限制，若要稳定保存生词本，建议用本地服务器（`python3 -m http.server`）或直接访问上面那个 GitHub Pages 地址。
